# Telegram Bot Admin Panel - Инструкция

## 📋 Описание

Реализована возможность редактирования информации в Telegram-боте через inline-кнопки.

## 🎯 Функционал

### Для администратора в Telegram:

1. **Панель тренера** (`/admin` или кнопка "👩‍🏫 Панель тренера")
   - 📋 Сегодняшние записи
   - 📊 Статистика
   - ✏️ **Редактировать** (новое!)

2. **Редактирование настроек**:
   - 💰 **Цены** - редактирование названий и цен абонементов
   - 📞 **Контакты** - редактирование телефона и адреса
   - 📅 **Расписание** - информация (редактируется через веб-админку)

### Как использовать:

1. Откройте панель тренера:
   - Нажмите кнопку "👩‍🏫 Панель тренера"
   - Или отправьте команду `/admin`

2. Нажмите "✏️ Редактировать"

3. Выберите, что хотите изменить:
   - **Цены**: Выберите абонемент → отправьте новую цену
   - **Контакты**: Выберите телефон/адрес → отправьте новое значение

## 🗄️ База данных

Новая таблица `settings` для хранения настроек:

```sql
CREATE TABLE settings (
    id SERIAL PRIMARY KEY,
    key VARCHAR UNIQUE NOT NULL,
    value VARCHAR NOT NULL,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### Ключи настроек:

**Цены:**
- `price_8_lessons_name`, `price_8_lessons_price`
- `price_6_lessons_name`, `price_6_lessons_price`
- `price_4_lessons_name`, `price_4_lessons_price`
- `price_single_name`, `price_single_price`
- `price_trial_name`, `price_trial_price`

**Контакты:**
- `contact_phone`
- `contact_address`

## 🔄 Синхронизация

### Веб-админка → Бот

При сохранении данных в веб-админке (`admin/index.php`) автоматически отправляется запрос на API бота:

```
POST http://bot:8000/api/settings/sync
```

### API эндпоинты бота:

- `POST /api/settings/sync` - синхронизация настроек
- `GET /api/settings` - получить все настройки

## 🚀 Развёртывание

1. **Перезапустите контейнеры:**
   ```bash
   docker-compose down
   docker-compose up -d
   ```

2. **База данных обновится автоматически** при старте бота (таблица `settings` создастся через `init_db()`)

3. **Проверьте работу:**
   - Откройте бота в Telegram
   - Нажмите "👩‍🏫 Панель тренера"
   - Нажмите "✏️ Редактировать"

## 🔧 Тестирование

### 1. Проверка БД:
```bash
docker exec -it zumba_bot psql -U zumba_user -d zumba_db -c "SELECT * FROM settings;"
```

### 2. Проверка API:
```bash
curl http://localhost:8000/api/settings
```

### 3. Тест синхронизации:
```bash
curl -X POST http://localhost:8000/api/settings/sync \
  -H "Content-Type: application/json" \
  -d '{"prices": {"8_lessons": {"name": "8 занятий", "price": "5000₽"}}}'
```

## ⚠️ Важно

- **Только администраторы** могут редактировать настройки (проверка по `ADMIN_IDS`)
- **FSM состояния** используются для диалога редактирования
- **Автоматическая синхронизация** при сохранении в веб-админке
- **Значения по умолчанию** используются, если настройки ещё не созданы
